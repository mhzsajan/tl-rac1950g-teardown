# TL-RAC1950G — English, local-only app build (v1.1.0)

English builds of **`com.tplink.ipc` 5.15.22.2003** for the **TL-RAC1950G 易展版**
(AC1950 EasyMesh). Goal: manage the router **locally, in English, without a
TP-LINK ID** — dashboard, Wi-Fi, internet settings, admin password, restart,
factory reset and **firmware upgrade**.

## Install

```powershell
adb uninstall com.tplink.ipc   # different signer than the vendor app
adb install -r tplink-router-en-slim.apk
```

Pick **slim** unless you also manage TP-Link cameras/NVRs (that build keeps the
camera/cloud payloads; slim drops them and is 65 MB smaller).

## What works (verified on a Galaxy S22 Ultra against a live TL-RAC1950G)

- first-run consent → home → local admin login → dashboard
- dashboard: network status, topology, connected devices, Wi-Fi, WAN type, guest
  network, restart, more settings — **all English**
- More settings: network + system settings, **Router software upgrade**
  *(shows both nodes: Main V2.0.16, Kitchen V2.0.12)*, change admin password,
  factory reset
- no TP-LINK ID needed: the binding prompt is answered "Not yet" and the router
  is managed locally
- all dumps on the tested screens contained **0 CJK characters**

## What changed in this release

- **Native resources translated too** — `resources.arsc` went from 92,351 CJK
  code points to ~0 (previously only the React Native UI was English)
- removed a stale `res/values-en/` that was overriding the corrected wording
- wording fixes: `All devices`, `Devices` tab, `Manage router`, `Unbound devices`,
  `Forgot password`, `Wireless schedule`, `Network management`,
  `connected devices`, `main router`
- muted one noisy toast — router API error `40101` ("Device system error!") that
  fired on the device / More settings pages; it is not a real failure

## Known limitations

- A few labels on router pages (`网络管理`, `%d台路由组网`) come **from the router
  itself**, which only ships a Chinese language pack — they cannot be changed in
  the APK.
- Debug-signed, so uninstall the vendor app first.
- Static plurals for edge counts ("1 devices").
